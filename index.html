How to get a token (2 min)
  1. On GitHub: tap your profile photo → Settings.
  2. Scroll down → Developer settings.
  3. Personal access tokens → Fine-grained tokens → Generate new token.
  4. Under "Repository access," choose Only select repositories → pick iron-log.
  5. Under "Permissions → Repository permissions," set Contents: Read and write.
  6. Generate, then copy the token here. GitHub only shows it once.
